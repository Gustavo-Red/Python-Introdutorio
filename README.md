## Como executar

Os exercícios são scripts independentes. Com Python 3 instalado, basta rodar:

```bash
python3 nome_do_arquivo.py
```

Cada script pede as entradas necessárias via terminal (`input()`). Alguns exercícios de manipulação de arquivos criam seus próprios arquivos de apoio (`.txt`/`.csv`) durante a execução.
